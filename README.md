# -Homemade-Naruto-Battle-Card-Game
已上传桌游模拟器，主要分为资一次性资源卡，技能卡两类。加入了主动权，拥有主动权一方的有更多优势，还原忍者快速决战的节奏。空白卡，这样的假动作增加了更多的心理博弈。/The Naruto card game mainly consists of two types: one-time resource cards and skill cards. It introduces initiative, where the side with the initiative has more advantages, recreating the fast-paced battles of ninjas. Blank cards are like fake moves.
